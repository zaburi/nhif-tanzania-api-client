# Contributing

Thanks for taking time to improve this package.

Before opening a pull request, please keep the change focused and explain the NHIF flow you tested. Do not commit real NHIF usernames, passwords, bearer tokens, patient names, NIDA numbers, card numbers, or authorization numbers.

For code changes:

- Run the TypeScript check.
- Use placeholder data in examples.
- Keep the public API small and easy to use.
- Mention any endpoint or response shape change in the changelog.
